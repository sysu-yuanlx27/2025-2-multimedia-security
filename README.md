## About The Course

The course introduces the foundations, principles, and techniques of multimedia information forensics and multimedia information hiding. It covers both theoretical concepts and hands-on methods used in multimedia security research.

Main topics include:

- Fundamentals of image data and multimedia information hiding
- Basic image steganography methods, including LSB replacement and LSB matching
- Steganalysis and hidden-message detection
- Distribution-preserving information hiding
- Deep-learning-based multimedia steganography and steganalysis
- Image, video, and audio information forensics
- Syndrome-trellis codes (STC)
- Adaptive steganography for spatial and JPEG images
